### 1. Spring Boot 4.0.3 → 4.0.8 — recommended action

Declared as the `org.springframework.boot` plugin version in `build.gradle` and as the
`spring-boot-starter-parent` version in `pom.xml`. Five patch releases have shipped on
the 4.0.x line since 4.0.3, and several carried security fixes:

- **4.0.4** (2026-03-19) — CVE-2026-22731 and CVE-2026-22733, both **Actuator
  authentication bypasses**
- **4.0.6** (2026-04-23) — CVE-2026-40976, CVE-2026-40977
- **4.0.7** (2026-06-10) — CVE-2026-40992, CVE-2026-41001
- **4.0.8** (2026-08-20) — current 4.0.x patch

This project declares `runtimeOnly 'org.springframework.boot:spring-boot-starter-actuator'`,
so the Actuator advisories are directly relevant. **4.0.3 → 4.0.8 is a
same-minor patch bump** and is the lowest-risk, highest-value upgrade available.

Also worth planning: **Spring Boot 4.0 reaches end of open-source support on
2026-12-31**, about four months out. The 4.1.x line (4.1.1, supported into
July 2027) is the forward-looking target, but that is a minor upgrade and should be
scheduled separately from the patch bump above.
