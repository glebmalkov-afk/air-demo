### Environment notes

Two environmental constraints affected this run. Both were worked around **without modifying any
source, build, or test file** — the exclusions and the toolchain path were passed as command-line
flags only.

1. **Docker daemon present, but the registry is unreachable.** `docker info` succeeds, so Docker
   itself is available, but image pulls fail at DNS resolution:

   ```
   Error response from daemon: failed to resolve reference "docker.io/testcontainers/ryuk:0.13.0":
   failed to do request: Head "https://registry-1.docker.io/v2/testcontainers/ryuk/manifests/0.13.0":
   dial tcp: lookup registry-1.docker.io on 10.69.0.2:53: read: connection refused
   ```

   Testcontainers cannot start its Ryuk reaper, so no Testcontainers-backed test can run. This is
   why the Docker-dependent tests were excluded in Run 2.

2. **No JDK 17 was installed.** `build.gradle` declares a Java 17 toolchain, but only JBR 25.0.2
   was present, and Gradle's toolchain provisioning API (`api.foojay.io`) is blocked by the
   network policy. The initial invocation failed during configuration:

   ```
   Cannot find a Java installation on your machine matching: {languageVersion=17, vendor=any vendor,
   implementation=vendor-specific, nativeImageCapable=false}. Toolchain download repositories have
   not been configured.
   ```

   Resolved by installing Temurin 17.0.20.1+1 into the environment and pointing Gradle at it with
   `-Porg.gradle.java.installations.paths=...`. No repository files were changed.

### Observation: unguarded integration test

`MySqlIntegrationTests` is annotated `@Testcontainers(disabledWithoutDocker = true)` and skips
cleanly when Docker is unusable. `PostgresIntegrationTests` has no equivalent guard and instead
fails with an initialization error. Since `PostgresIntegrationTests` drives containers through
`spring.docker.compose.skip.in-tests=false` rather than the `@Testcontainers` extension, it needs a
different guard, but the effect is the same: **any environment without container-registry access
sees a red build instead of a skip.** Flagged only — no code was changed, per the report rules.
