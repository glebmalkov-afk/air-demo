### Toolchain note (build portability)

The first invocation of `./gradlew test` failed during **configuration**, before compiling anything:

```
> Failed to calculate the value of task ':compileTestJava' property 'javaCompiler'.
   > Cannot find a Java installation on your machine matching:
     {languageVersion=17, vendor=any vendor, ...}. Toolchain download repositories
     have not been configured.
```

`build.gradle` requires a Java 17 toolchain (`JavaLanguageVersion.of(17)`), the runner only had
JDK 25, and the project declares **no toolchain download repository** (e.g. the Foojay resolver),
so Gradle could not auto-provision one. Any machine or CI image without a pre-installed JDK 17
hits this wall. It was worked around for this run by installing Temurin 17.0.9 locally and passing
`-Porg.gradle.java.installations.paths=...` on the command line — **no build files were modified**.
Adding a toolchain resolver plugin to `settings.gradle` would make the build self-sufficient.
