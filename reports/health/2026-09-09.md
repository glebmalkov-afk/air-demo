     matching: {languageVersion=17, vendor=any vendor, ...}.
     Toolchain download repositories have not been configured.
```

Root cause and why it could not be worked around cleanly:

- `build.gradle` pins `languageVersion = JavaLanguageVersion.of(17)`.

  filesystem-wide search found no other JDK.

  `settings.gradle`), so Gradle cannot fetch a JDK 17 itself.

  `download.java.net` are both blocked by the outbound proxy (`CONNECT tunnel

#### Docker / Testcontainers note

The Docker **daemon is running and reachable** (`docker info` succeeds), so
Testcontainers-dependent tests were not pre-emptively skipped. However, the daemon
**cannot reach Docker Hub** — DNS resolution for the registry is refused:

```

Consequences:

- `PostgresIntegrationTests` (1 test) **failed** — it could not pull the Ryuk
  sidecar image.

  `@Testcontainers(disabledWithoutDocker = true)`, and Testcontainers classified
  Docker as unusable for the same reason.

Both outcomes are environmental. Neither indicates a defect in the application
code. Every non-container test class passed.
