### ℹ️ Infrastructure note: Java 17 toolchain had to be provisioned

The first `./gradlew test` invocation failed during configuration, before compiling
anything:

```
> Failed to calculate the value of task ':compileTestJava' property 'javaCompiler'.
   > Cannot find a Java installation on your machine matching:
     {languageVersion=17, vendor=any vendor, ...}
     Toolchain download repositories have not been configured.
```

The runner provides only JBR 25.0.2, but `build.gradle` requests a Java 17 toolchain,
and the build declares no toolchain-download repository. Temurin 17.0.20.1 was
downloaded to `/tmp/jdk17` and passed in **on the command line only**:

```
./gradlew test --no-daemon -Porg.gradle.java.installations.paths=/tmp/jdk17
```

No build file was touched to make this work. Two follow-ups for whoever owns CI:
pre-install a JDK 17 on the runner, **or** register a toolchain resolver (e.g. the
Foojay plugin in `settings.gradle`) so the toolchain resolves on its own. Also note the
egress proxy blocks `repo1.maven.org` and `api.adoptium.net` (both HTTP 403) while
allowing `github.com` — this build only succeeded because the Gradle dependency cache
was already warm (336 MB under `~/.gradle`). A cold cache would fail to resolve
dependencies in this environment.
