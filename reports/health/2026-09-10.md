missing roughly four patch releases of fixes on its own line — the cheapest, lowest-risk
upgrade available here is 4.0.3 → latest 4.0.x. Spring Boot 4.1 keeps Java 17 as its minimum,
so the pinned toolchain is not an obstacle to the minor bump either.

**Bootstrap 5.3.8** — already on the newest stable release, and 5.3.8 is expected to be the
final patch on the 5.3 line before 5.4. Bootstrap 6 is in alpha on `v6-dev`, is not published
to npm, and carries breaking changes (Tailwind-style responsive prefixes, Modal → Dialog,
ESM-only). No action.

**Font Awesome 4.7.0** — the standout finding. Version 4 is end-of-life; the current line is 7.x
(7.3.1). That said, upstream spring-petclinic has deliberately stayed on FA4 because the
Thymeleaf templates use v4 glyph names, and a jump to v6/v7 is a template migration rather
than a version bump. Worth tracking as known, accepted debt rather than treating as a routine
upgrade.
