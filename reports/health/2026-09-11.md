### Environment note (not a repo defect)

The first invocation of `./gradlew test` failed during configuration, before any test
ran:

```
> Failed to calculate the value of task ':compileTestJava' property 'javaCompiler'.
   > Cannot find a Java installation on your machine ... matching:
     {languageVersion=17, vendor=any vendor, ...}.
     Toolchain download repositories have not been configured.
```

`build.gradle` pins the Java toolchain to 17, but the only JDK present in this runner
was JDK 25 (JetBrains Runtime), and the project does not configure a toolchain
resolver plugin, so Gradle could not auto-provision one. This was resolved by
installing Temurin JDK 17.0.20.1 into the runner and pointing Gradle at it via the
command line (`-Dorg.gradle.java.installations.paths=...`). **No build file, source
file, or test was modified.** The toolchain pin itself is a deliberate and correct
choice for a Java 17 project; the gap was in the runner image, not the repository.
Flagged only so that whoever provisions CI knows a JDK 17 must be present.
