### ⚠️ Environment note — Java 17 toolchain not present

The first invocation of `./gradlew test` failed during configuration:

```
> Failed to calculate the value of task ':compileTestJava' property 'javaCompiler'.
   > Cannot find a Java installation on your machine (Linux ... amd64) matching:
     {languageVersion=17, vendor=any vendor, ...}. Toolchain download repositories
     have not been configured.
```

`build.gradle` requests `JavaLanguageVersion.of(17)`, the only JDK on this runner is JBR 25.0.2,
and no toolchain resolver (e.g. the Foojay plugin) is configured in `settings.gradle`, so Gradle
could neither find nor auto-provision a JDK 17. This is a **runner/environment gap, not a repo
defect** — the project's own CI workflows provision a JDK before building.

To get an honest test result without touching any build file, a Temurin 17.0.20.1+1 JDK was
downloaded to `/tmp` and passed in on the command line only:

```
./gradlew test -Porg.gradle.java.installations.paths=/tmp/jdks/jdk-17.0.20.1+1
```

All counts above come from that run. No project file was modified to make it work.
